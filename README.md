A collection of **SQL concepts, queries, and practical implementations** documenting my learning journey in database management and data analysis.

This repository focuses on building a strong foundation in SQL through query writing, database operations, and hands-on examples used in data analysis, reporting, and business intelligence.

---

## Topics Covered

### SQL Fundamentals
* SQL Syntax & Execution Order
* Data Types & Schema Design
* Database Creation (`CREATE DATABASE`)
* Table Creation (`CREATE TABLE`)
* Integrity Constraints (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`)

### Data Retrieval & Filtering
* `SELECT` Statements
* Filtering Data with `WHERE` Clause
* Sorting Results with `ORDER BY`
* Unique Values with `DISTINCT`
* Pagination with `LIMIT` / `OFFSET`
* Column and Table Aliases (`AS`)

### Aggregate Functions & Grouping
* Summary Functions (`COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`)
* Grouping Data with `GROUP BY`
* Filtering Aggregates with `HAVING`

### Joins & Relationships
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL OUTER JOIN
* SELF JOIN & Cross Joins

###  Advanced SQL Concepts
* Subqueries & Correlated Subqueries
* Common Table Expressions (`WITH` CTEs)
* Window Functions (`ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`)
* Conditional Logic with `CASE` Statements
* Virtual Tables (`CREATE VIEW`)

###  Database Operations (DML & DDL)
* Inserting Data (`INSERT INTO`)
* Updating Records (`UPDATE`)
* Deleting Records (`DELETE` vs `TRUNCATE`)
* Schema Modifications (`ALTER TABLE`, `DROP TABLE`)
